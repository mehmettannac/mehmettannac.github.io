# Mehmet Annac — Kişisel Web Sitesi

Web Tasarımının Temelleri dersi vize projesi. Tema: **Blueprint × Night Ride**. Mimari çizim ızgarası ile gece neon ışıklarını birleştiriyor.

- Saf HTML, CSS ve JavaScript ile yazıldı; framework kullanılmadı.
- Türkçe/İngilizce dil desteği var (sağ üstteki TR / EN düğmesi).
- Mobil öncelikli ve responsive.
- SEO/GEO: her sayfanın kendi title ve description etiketi var. Ayrıca Open Graph etiketleri, Person JSON-LD, `sitemap.xml`, `robots.txt` ve `llms.txt` eklendi.

## Sayfalar

| Dosya | Sayfa |
|---|---|
| `index.html` | Anasayfa |
| `hakkimda.html` | Hakkımda: vesikalık, özgeçmiş, ders programı tablosu, yetenekler (%), listeler |
| `projeler.html` | Grafik Animasyon 1 projeleri |
| `blog.html` + `blog-*.html` | Blog: 3 yazı |
| `galeri.html` | Galeri |
| `iletisim.html` | İletişim bilgileri ve form |

## Proje görsellerini eklemek

Görselleri `assets/img/projeler/` klasörüne şu adlarla koy: `proje1-sonrasi.jpg`, `proje2-sonrasi.jpg` … `proje6-sonrasi.jpg`.
Kodda değişiklik yapmana gerek yok, görsel kartta kendiliğinden görünür.

## Yayın

GitHub Pages'te yayınlamak için: **Settings → Pages → Branch: main / (root)**.
