Python'a merhaba: neden ilk dilim olarak seviyorum?Hello Python: why I love it as my first language

Okunabilir sözdizimi, güçlü kütüphaneler ve Django'ya açılan kapı: Python'u neden sevdiğimi küçük örneklerle anlatıyorum.Readable syntax, powerful libraries and a door to Django: why I love Python, with small examples.

Mehmet Annac~4 dk~4 min

Bilgisayar Programcılığı'nda en sevdiğim dil şu an Python. İlk bakışta neredeyse İngilizce bir cümle gibi okunuyor; bu da yeni başlayan biri için büyük bir avantaj.

Okunur kod

Küçük bir örnek: ders programımdaki bazı derslerin haftalık saatlerini topluyorum.

dersler = {
    "Programlamanın Temelleri": 4,
    "Veri Tabanı I": 4,
    "Grafik Animasyon I": 4,
    "Web Tasarımının Temelleri": 2,
}
toplam = sum(dersler.values())
print(f"Bu derslerde haftada {toplam} saat geçiriyorum.")

Süslü parantez yok, noktalı virgül yok. Girintiler zorunlu olduğu için kod kendiliğinden düzenli duruyor; teknik çizimdeki katman düzeni gibi.

Tek satırda liste: list comprehension

4 saatten uzun süren dersleri ayıklamak için tek satır yetiyor:

uzun = [ad for ad, saat in dersler.items() if saat >= 4]

Neden Python?

  • Öğrenmesi kolay: sözdizimi sade, hata mesajları anlaşılır.
  • Her yerde: web, veri analizi, otomasyon ve yapay zekâ projelerinde kullanılıyor.
  • Django'ya kapı: web uygulaması yazmak istediğimde aynı dili kullanmaya devam edebiliyorum.

Django tarafını bir sonraki yazıda anlattım: Django'yu bir mimar gibi düşünmek →

Right now my favourite language in Computer Programming is Python. At first glance it reads almost like an English sentence, which is a big advantage for a beginner.

Readable code

A small example: adding up the weekly hours of some courses in my timetable.

dersler = {
    "Programlamanın Temelleri": 4,
    "Veri Tabanı I": 4,
    "Grafik Animasyon I": 4,
    "Web Tasarımının Temelleri": 2,
}
toplam = sum(dersler.values())
print(f"Bu derslerde haftada {toplam} saat geçiriyorum.")

No curly braces, no semicolons. Indentation is required, so the code stays tidy on its own — like the layer order in a technical drawing.

A list in one line: list comprehension

Filtering the courses that take 4 hours or more needs just one line:

uzun = [ad for ad, saat in dersler.items() if saat >= 4]

Why Python?

  • Easy to learn: simple syntax and readable error messages.
  • Everywhere: used in web, data analysis, automation and AI projects.
  • A door to Django: when I want to build a web app, I can keep using the same language.
